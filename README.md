# CampusConnect – Smart Campus Complaint & Support Portal

A beginner-friendly academic web project built with HTML, CSS and JavaScript.

## Features
- Responsive landing page
- Campus issue reporting form
- Automatic complaint ID generation
- Complaint tracking
- Recent reports dashboard
- LocalStorage-based demo data

## Run
Open `index.html` in a browser.

## Demo
Use complaint ID `CC-2026-1001` in the Track section.

## Future Scope
Backend/database, student login, admin dashboard, notifications and AI-based complaint categorization.
